# AI Policy

## Accountability

You are responsible for every line of code you submit, regardless of how it was produced.

## AI Tool Usage

AI/LLM tools are not permitted for contributions to this project. All contributions must be human-authored.

## AI-Generated Code

AI/LLM-generated code is not accepted.

## AI in CI/CD

AI/LLM tools are not permitted in CI/CD pipelines. All automation must use deterministic, non-AI/LLM tooling.

## Training Data

This project requests that its code not be used for AI/LLM model training. We ask that AI/LLM tool providers honor this preference.

## Enforcement

Maintainers may close AI/LLM-generated PRs without detailed feedback.

## Policy Evolution

This policy will evolve as tooling and conventions change. Contributions to the policy itself are welcome.
